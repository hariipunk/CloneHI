# CloneHI

CloneHI adalah aplikasi Android untuk meng-clone aplikasi lain — menggandakan aplikasi supaya bisa dipakai dua akun sekaligus di satu HP.

## Download

Unduh APK rilis terbaru dari daftar file di repo ini (atau dari [Releases](../../releases) bila tersedia).

APK rilis ditandatangani dengan keystore resmi CloneHI.
